# Parcours d'apprentissage — chaîne logistique Chine → Cameroun

22 modules, en 7 parties. Un module = une idée. Aucun terme de métier n'est
utilisé avant d'avoir été défini. Chaque chiffre porte sa source, et ce qui est
inconnu est signalé comme tel.

## Les règles du parcours

1. **Aucun mot de métier sans définition**, dès sa première apparition.
2. **Un module = une seule idée.** On n'avance que quand c'est acquis.
3. **Chaque chiffre a sa source.** 🟢 texte officiel · 🟠 estimation
   professionnelle · 🟡 inventé pour l'exercice.
4. **Si je ne sais pas, je le dis.**
5. **Un exemple concret systématique**, tiré du conteneur en cours.
6. **Fin de module** : ce qu'il faut retenir + un mini-test.
